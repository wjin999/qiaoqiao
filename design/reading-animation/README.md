# 翻书动画样片 01

预览：启动 `npm run dev -- --host 127.0.0.1`，打开 `http://127.0.0.1:5173/design/reading-animation/`。

这是独立动画检查页，已获用户确认并接入正式练习界面，不更改学习记录或宠物成长。金毛、黑白猫各使用八帧连续画面，四列两行；播放顺序为先上排后下排。仅切换绘制好的画面，没有整体旋转、缩放、平移或用半透明叠图假装中间帧。

正式素材副本位于 src/assets/companions/golden-turn.png、tuxedo-turn.png。默认书本每六秒自动翻页，或由“翻一页”触发；动作保持样片每帧 180ms 的节奏，末帧停留 300ms。其他书仍使用已有静态封面。关闭自动翻页或系统减少动态效果时停用动作，后台暂停。打字重渲染不会重新开始动作。

每次循环停留阅读后执行抬爪、触碰页角、掀页、翻过书脊、书页落下、收爪、继续阅读。支持播放、暂停、重播、逐帧、慢放、两种显示大小和三种背景。后台暂停播放；系统减少动态效果时默认暂停。

最终素材：本目录 `golden-turn.png`、`tuxedo-turn.png`。使用内置 imagegen 根据已批准的角色图生成，并单独修正背景。完整提示词见 `prompts.md`。

检查重点：爪子是否跟着书页运动；身体和书封是否抖动；循环是否跳帧；深色/棋盘背景下是否有残留；页面大小下动作是否清楚。当前只有各一本书的翻页样片。
