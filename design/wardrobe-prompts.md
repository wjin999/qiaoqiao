# 伙伴服装素材

使用内置 image_gen 工具，以原始角色为参考绘制。素材保存于 `src/assets/companions/`；每套包含 poses（三姿势）、reading（四本书）、turn（八帧翻页），保留 PNG 透明通道。

## 提示词

Use case: identity-preserve. Preserve slim cute anatomy, face, coat markings, expression, painterly illustration style. Production transparent PNG sprite sheet: exactly THREE equal width cells in ONE horizontal row, idle seated / leaning and pressing single keyboard key / seated cheering with ONE raised front paw. Each full animal centered in its cell, keep generous 8% transparent gutter ALL sides of each cell; no piece crosses a cell boundary. Same clothing design in all poses, clothing follows limbs. Exactly four limbs per pet, no extra paws, no floating garment. NO background, true alpha transparency, no shadows outside silhouette, no frames, no text or labels, no added accessories. Landscape 3:1 canvas.
