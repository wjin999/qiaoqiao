# 日语敲敲角色草案

三套原创角色概念，供挑选。每张从左到右是待机、敲字、庆祝；目前为静态设计稿，尚未接入练习或养成系统。

- **敲敲鼹**：拿木槌的小鼹鼠，和项目名呼应，适合成为主角色。
- **米米雀**：站在键帽上的小文鸟，安静陪伴，完成练习后扑翅庆祝。
- **芽芽团**：长出嫩芽的糯米团，适合用发芽、开花表现成长。

图标方向是「小木槌敲键帽」，见 `branding/mallet-icon.svg`。它是独立的矢量草案，尚未替换网站图标。

运行开发服务器后打开 `/design/index.html`，可一起查看角色稿和图标的不同尺寸。

角色使用内置 image_gen 生成，完整提示词见 `prompts.json`；SVG 图标由代码绘制。原图保存在 `mascots/`。
