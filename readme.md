# 日语敲敲 · qiaoqiao

敲敲键盘，记住日语。通过日语例句练习汉字读音、助词与句型。

**[在线使用](https://wjin999.github.io/qiaoqiao/)**

## 使用

- 内置 egg rolls JLPT N5–N1 卡组，共 15,891 条例句与短语，支持中文翻译和假名注音。
- **记忆复习**：先尝试回忆读音，完成跟打后显示注音并锁定输入；按 **1 重来 / 2 困难 / 3 良好 / 4 简单** 评分。使用 FSRS 安排到期复习，每天默认最多引入 10 个新句，可调整。
- **自由跟打**：随机选句、默认显示注音，完成后按 Enter 继续，不改变记忆复习计划。
- 自动记住上次选择的卡组及各卡组的练习范围；跟打时按 Tab 切换汉字注音。
- 大金毛「麦麦」和黑白猫「点点」可选，完成并保存一句成长 +1；支持关闭陪练或动画。登录后完成一组自动同步学习进度、宠物成长和设置，也可手动同步。
- 可导入自己的 Anki `.apkg` 卡组，需包含日语和中文字段；仅提取文本及已有注音，不导入媒体或复习进度。
- 不登录也能练习；记录逐句保存在浏览器。邮箱登录后，点击「同步」同步进度、设置和自定义卡组，首页可查看学习活动热图。
- 支持导出／恢复 JSON 进度备份，兼容旧版 TypeLingo 备份。清除网站数据会删除尚未同步的记录，请定期备份并保留原始 `.apkg` 文件。

## 本地运行

需要 Node.js 24 或更高版本。

```bash
npm ci
npm run dev
```

`npm test` 运行测试，`npm run build` 构建网页。推送到 `main` 后自动发布至 GitHub Pages。

账号同步的数据库、邮件与部署配置见 [云同步配置](docs/cloud-sync.md)。未配置公开 API key 时，网站仍可作为本地练习工具使用。
