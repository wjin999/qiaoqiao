# 日语敲敲 · qiaoqiao

敲敲键盘，记住日语和英语。通过例句练习日语的汉字读音、助词与句型，以及英语的拼写与词序。

**[在线使用](https://wjin999.github.io/qiaoqiao/)**

## 使用

- 日语：内置 egg rolls JLPT N5–N1 卡组，共 15,891 条例句与短语，支持中文翻译和假名注音。
- 英语：与日语相同的排版，上方中文、中间英文、下方输入；目前内置 10 个示例句供试用，正式英文卡组由作者后续提供。
- **记忆复习**：先尝试回忆读音，完成跟打后显示注音并锁定输入；按 **1 重来 / 2 困难 / 3 良好 / 4 简单** 评分。使用 FSRS 安排到期复习，每天默认最多引入 10 个新句，可调整。
- **自由跟打**：随机选句、默认显示注音，完成后按 Enter 继续，不改变记忆复习计划。
- 自动记住学习语言和练习范围；日语跟打时按 Tab 切换汉字注音。
- 如果想使用自己的 Anki 卡组，请联系作者。
- 不登录也能练习；记录逐句保存在浏览器。邮箱登录后，完成一组自动同步学习记录（卡组和设置只保存在本机），也可点击「同步」手动同步；首页可查看类似 GitHub 的学习活动热图。
- 支持导出／恢复 JSON 进度备份，兼容旧版 TypeLingo 备份。清除网站数据会删除尚未同步的记录，请定期备份。

## 本地运行

需要 Node.js 24 或更高版本。

```bash
npm ci
npm run dev
```

`npm test` 运行测试，`npm run build` 构建网页。推送到 `main` 后自动发布至 GitHub Pages。

账号同步的数据库、邮件与部署配置见 [云同步配置](docs/cloud-sync.md)。未配置公开 API key 时，网站仍可作为本地练习工具使用。
